Communication

How services talk

Four edges across two regions. Mixed sync, async, and data access.

📦 Orders → 💳 Billing HTTP · sync
💳 Billing → Ledger Bus event · async
🔐 Auth → User DB SQL · data
📦 Orders → Orders Warehouse SQL · data

Observation. The only cross-region writes go through the Ledger Bus (async) or via per-service SQL writers — no service in the Platform region reaches across to a store it doesn't own.

Open decisions

Two things the team flagged

DECISION · OPEN

Move pricing out of Billing

"We agreed at standup that the billing service should not own pricing — move pricing-related endpoints to Orders next sprint."
  • Touches: Billing, Orders
  • Why: clearer domain ownership; Orders already owns the catalog read path
  • Next: scope the endpoint list this week, schedule for next sprint
COMPLIANCE · OPEN

Warehouse retention = 90 days

"Warehouse retention is 90 days — flag this in the deck so legal can sign off."
  • Touches: Orders Warehouse
  • Risk: any analytics or audit use case past 90 days will fail silently
  • Next: send retention summary to legal before sprint planning
